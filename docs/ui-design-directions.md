# LibreTV UI 重构设计方案

本次首页重构围绕“影视发现”展开：搜索是首要动作，推荐内容是第二入口，片源状态与历史入口保持可达。现有数据查询、卡片点击、点播源设置和播放流程不变，仅更新信息层级、视觉层和响应式布局。

## 响应式结构

| 区间 | 布局 | 关键行为 |
| --- | --- | --- |
| 320–639px 手机 | 顶栏图标化；推荐封面 2 列；搜索框满宽；结果卡单列横向 | 下载入口收进设置，触控目标不小于 44px |
| 640–1023px 平板 | 顶栏保留文字导航；推荐 4 列；结果 2 列 | 搜索区保持居中，筛选标签换行 |
| 1024px+ PC | 7xl 内容容器；推荐 6–8 列；结果 3 列 | 顶栏固定，搜索区有更大上下留白 |

## 四套视觉方向

### 霓虹影院（当前实现方向）
- 深蓝黑底、青蓝主色、粉色品牌渐变，延续 LibreTV 已有暗色资产。
- 首屏用“跨站搜索 · 一站发现”建立产品认知，主标题聚焦“找到下一部好片”。
- 适合重度用户与夜间观影；建议作为默认主题，降低迁移成本。

### 杂志编辑部
- 暖米白底、衬线标题、深绿色操作色，强调片单和内容策展。
- 推荐区可增加编辑短评、导演/类型筛选；适合品牌化运营和内容专题。
- 需要补充字体加载与更严格的海报裁切规范。

### 流光玻璃
- 低饱和蓝紫渐变背景、半透明导航和搜索框、轻阴影。
- 将“发现”做成沉浸式入口，适合年轻用户和大屏展示。
- 需要控制透明层数量，弱网和低端手机默认关闭 backdrop-filter。

### 暖白极简
- 暖白底、橙色动作色、细边框和大留白，突出搜索效率。
- 信息密度最低，适合家庭设备、长时间浏览和浅色主题用户。
- 推荐卡片保持高对比文字，避免橙色大面积占屏。

## 组件规则
- 顶栏：品牌、直播、关于、主题、历史、下载、设置；手机隐藏次要文字导航和下载快捷入口。
- 搜索：输入与按钮合并为一个操作单元，手机按钮缩短为图标/短文案，历史下拉与输入框保持同一边界。
- 推荐：类型切换在标题旁，标签可换行；手机双列，PC 6–8 列。
- 搜索结果：聚合卡片保持来源数量、画质、集数和播放动作；失败提示放在结果标题下方。
- 无障碍：保留现有键盘操作、aria-label、焦点环和语义按钮；正文和辅助文字遵循 AA 对比度。
